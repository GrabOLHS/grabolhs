Grab OLHS Courses

Interested in what another class is learning? Self studying for an AP Exam? Deciding what classes you want to take next year, but aren't sure what your getting into? Explore the course directory to find the Schoology materials page for any of the 1000+ classes currently in the database.

    Important Information:

  • You must have a valid Liberty Schoology account for this site to work.
  • It (likely) does not (currently) work for other schools.
  • You are NOT able to submit tests, quizzes, files to submission dropboxes, or comment on discussion post.... (yet)
  • However, say something like an external website with a join code, like this Discrete Math one for example, you could join it since the code is public.
  • Also, for some reason it allows you to see the titles of unpublished folders, but no content inside of it.
  • Important!!!: MANY courses will have nothing in it. A lot of times this is because they are for Semester 2 courses, or the course just doesn't need any Schoology materials. I'd check every search result and make sure that all of the courses don't contain any materials before giving up on finding the course's materials.
